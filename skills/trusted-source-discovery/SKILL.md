# Trusted Source Discovery

Use this skill to propose new property-listing sources without activating them.

1. Obtain candidates only from an approved search API, public directory, or a user-provided URL.
2. Create a pending-review record containing domain, city coverage, discovery query, timestamp and evidence URL.
3. Check terms of use, robots.txt, rate limits, listing provenance and a bounded sample response.
4. Never solve CAPTCHAs, bypass login, scrape private content, or activate a source automatically.
5. A platform administrator must explicitly change `pending_review` to `active`.
